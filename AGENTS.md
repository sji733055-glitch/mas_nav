# Repository Instructions

## Change history

Every task that changes source code, configuration, scripts, assets, or documentation must append an entry to `docs/change-history.md` before handoff.

Each entry must include:

- the date and a short title;
- the behavior changed and the main files/components involved;
- verification performed, including anything not tested.

Append new entries at the top of the history section. Do not rewrite or delete older entries. Documentation-only changes are changes and must also be recorded.
